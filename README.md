### 为什么是 SALA + 1/23

- **画面**：迈考正西，1/23 太阳真正落进海里；沙滩、草坪、蓝调一条线拍完。
- **长辈**：机场近、平地多、直通沙滩；不用每天爬坡等 buggy。
- **日期**：1/23 是大利月里唯一「周六 + 除日 + 金匮 + 宜嫁娶」全占的一天。
- **预算**：5 人走 Simple 档，钱可以留给摄影、主纱和房型。

### 必须接受的代价

- 公共海滩，不能封闭，可能有游客入镜。
- 沙滩不宜游泳，无救生员；长辈想下水只能去泳池。
- Sirinat 国家公园：**无无人机、无烟花、无天灯**；户外音乐至 22:30。
- 迈考在机场航线下，仪式可能拍到低空航班，收音也可能受影响。
- 装修略旧、露天浴室虫多、早餐口碑不稳定。
